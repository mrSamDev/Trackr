# Changelog

All notable changes to Trackr.

## [1.2.0] - 2025-05-14

### Added
- MCP OAuth 2.1 support for secure AI assistant integration
- Application filtering by status and date range
- Analytics dashboard with interactive charts
- Keyboard shortcuts for common actions

### Changed
- Improved OAuth token refresh mechanism
- Enhanced error messages for MCP tools
- Updated documentation structure

### Fixed
- Resolved issue with OAuth callback URL mismatch
- Fixed analytics chart rendering on mobile devices
- Corrected database migration order

## [1.1.0] - 2025-04-20

### Added
- Better Auth integration with GitHub OAuth
- tRPC v11 for type-safe APIs
- TanStack Start framework upgrade
- Drizzle ORM for database management

### Changed
- Migrated from cookie-based auth to OAuth
- Updated database schema with userId fields
- Improved API response times

### Fixed
- Session management issues
- Database locking problems
- CORS configuration for MCP clients

## [1.0.0] - 2025-03-15

### Added
- Initial release
- Job application tracking
- Basic analytics dashboard
- MCP server for AI assistant integration
- SQLite database with Drizzle ORM
- GitHub OAuth authentication
- Responsive UI with Tailwind CSS
- Comprehensive documentation
