Trackr v1.2: OAuth 2.1 & Enhanced MCP Integration

May 14, 2025 · 3 min read
Sam O.
Maintainer

Author: Sam O.

We're excited to announce Trackr v1.2.0, featuring OAuth 2.1 support for secure AI assistant integration and an enhanced analytics dashboard.

What's New​

🔐 OAuth 2.1 for MCP​

The biggest addition in v1.2 is OAuth 2.1 support for MCP (Model Context Protocol) clients. This means:

  • Secure authentication for AI assistants like Claude and Cursor
  • Token-based access with automatic refresh
  • Scoped permissions for fine-grained control
  • Industry-standard OAuth 2.1 compliance

Connect your AI assistant securely:

{
  "mcpServers": {
    "trackr": {
      "command": "bun",
      "args": ["run", "src/mcp-applications.ts"],
      "auth": "oauth"
    }
  }
}

📊 Enhanced Analytics Dashboard​

The analytics dashboard now features:

  • Interactive charts with hover details
  • Time range filtering (7/30/90 days, custom)
  • Export capabilities (PNG, SVG, CSV)
  • Mobile-responsive design
  • Keyboard shortcuts for power users

Migration Guide​

For Existing Users​

If you're upgrading from v1.1:

  1. Backup your database:

    cp trackr.db trackr.db.backup

  2. Install dependencies:

    bun install

  3. Run migrations:

    bun run db:migrate

  4. Update OAuth settings (if using MCP):

    • Regenerate GitHub OAuth credentials
    • Update .env with new secrets

For New Users​

Get started in minutes:

git clone https://github.com/mrsamdev/trackr.git
cd trackr
bun install
bun run dev

Visit Getting Started for detailed setup instructions.
